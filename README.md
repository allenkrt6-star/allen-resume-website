# Allen Kurt Dela Peña — Mid-Fidelity Resume Website

A responsive, static HTML/CSS resume website with a black, white, and gray theme. It includes a collapsible mobile sidebar, clickable section navigation, skills/interests, education, and contact placeholders.

## Files
- `index.html` — page content and small navigation script
- `style.css` — responsive layout and styling

## Preview locally
1. Open this folder in Visual Studio Code.
2. Open `index.html`.
3. If you have the Live Server extension, choose **Open with Live Server** or click **Go Live**.
4. Otherwise, you can open `index.html` directly in Chrome for a basic preview.

## Before publishing
In `index.html`, replace:
- `YOUR_EMAIL@example.com` with your email address
- `YOUR_USERNAME` with your GitHub username
- The `ADP` initials placeholder can stay, or you can replace it with an image if you want

Review all details for accuracy before making the repository public.

## Publish using GitHub Pages
1. Sign in to GitHub and create a **Public** repository (for example, `my-resume`).
2. Upload `index.html` and `style.css` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for deployment, then use **Visit site** on the Pages settings page.

The URL normally follows this pattern:
`https://YOUR_USERNAME.github.io/my-resume/`

GitHub Pages publishing can take a few minutes. A public website may be visible to anyone who has the link.
